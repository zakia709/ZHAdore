# ZHADORE

Fashion portfolio site — Collection 2026.

## Preview locally

The site is a single static file with no build step. Any static server works:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

Or with Node:

```bash
npx serve .
```

## Deploy

Drop the repo into any static host (Vercel, Netlify, Cloudflare Pages, GitHub Pages). No build command needed — `index.html` is the entry point.
